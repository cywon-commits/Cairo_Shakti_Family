# Claude Code 작업 지시서: A|C 1차 전이의 유한 크기 스케일링

## 배경 (한 문단)
카이로(d) 격자의 다이머 매니폴드 안에서 장거리 쌍극자는 카이로 쪽에서 A(결합 방향 질서), 샥티 쪽에서 C(부격자 질서)를 고른다.
T=0 전이점은 d_c ≈ 0.153 (바늘 모델, 간격 g=0). 8×8 병렬 템퍼링에서 d=0.145는 A(T≤0.085) → C형(T≥0.2) 재진입을 보였고,
T≈0.117에서 에너지 분포가 두 봉우리(A: E/N≈−39.840, C: ≈−39.832)로 갈라졌다. 이것이 진짜 1차 전이인지 유한 크기 스케일링으로 확정하는 것이 목표다.
자세한 경과는 README.md 마지막 절들("A-C competition at finite T" 등)에 있다.

## 코드 구성 (이 폴더)
- `cairo_asi.py` 격자 CairoLattice(nx, ny, d), 관측량, numba SA
- `needle.py`, `hybrid_coupling.py` 쌍극자 결합: `local_needle_coupling(L)` (매니폴드 정의), `hybrid_coupling(L, rc)` (전체 쌍극자, 섬 단위 cutoff). 반드시 `needle.GAP = 0.0` 확인
- `manifold_mc2.py` 매니폴드 보존 MC (`mc_arrays`, `mc`)
- `selection_T.py` `FastDimers` (질서변수 ψ_A, ψ_C)
- `pt_joint.py` 현재의 PT 스크립트 (n=8 고정, 출발 상태 A/C 교대, (ψ_A, ψ_C, E) 표본 저장) — 이것을 일반화할 것
- `plot_phases.py`의 `tile()` 4×2 상태를 n×n으로 타일링. 참조 상태: `scan3_min_d0.1372.npy` (A), `scan3_min_d0.2500.npy` (C)
- 필요 패키지: numpy, scipy, numba, matplotlib

## 할 일
1. `pt_joint.py`를 일반화: 계 크기 n을 인자로, 온도 사다리를 전이 부근(T = 0.08–0.20)에 촘촘하게, 체크포인트/재시작 지원, 여러 seed.
2. d = 0.145에서 n = 8, 12, 16, 20 (가능하면 24). n은 4의 배수여야 A·C와 주기가 맞는다.
   - 각 n마다 A 출발과 C 출발 PT를 독립적으로 돌려 결과 일치로 평형 확인. 교환 수용률 ≥ 0.2가 되도록 복제본 수 조절.
   - 에너지 자기상관시간을 재고, 측정 표본 수가 자기상관시간의 수백 배 이상이 되게 한다.
3. 분석 (다중 히스토그램 재가중, WHAM):
   - 두 봉우리 높이가 같아지는 T*(n)에서 P(E): 장벽 ΔF(n) = ln(P_max / P_min). 2차원 1차 전이면 ΔF ∝ n (계면 비용 2σL)으로 커져야 한다.
   - 비열 최대값 C_max(n): 1차 전이면 ∝ n² (N에 비례), T*(n) − T*(∞) ∝ 1/n².
   - 잠열: 두 봉우리 위치 차이, n → ∞ 외삽.
   - 에너지 Binder 누적량 V = 1 − ⟨E⁴⟩/(3⟨E²⟩²)의 최솟값이 2/3와 다른 값으로 수렴하는지.
4. (여유가 되면) d = 0.140, 0.1475, 0.150, 0.1527에서 같은 분석으로 (d, T) 평면의 A|C 선을 그린다.

## 주의
- `hybrid_coupling`의 근거리장 부분은 파이썬 루프라 n이 크면 느리다(n=16: 수 분, n=24: 수십 분). 결합 행렬을 npz로 캐시할 것. 필요하면 근거리 쌍 계산을 벡터화.
- 매니폴드 MC의 한 sweep 비용은 대략 N²에 비례한다. n=24(스핀 5,760개)는 무거우니 n=20까지를 우선 목표로.
- 전체 쌍극자 cutoff는 rc = 64a를 유지(A|C 경계는 rc ≥ 16a에서 수렴 확인됨).
- 출발 상태가 A/C 교대이므로, 저온 복제본이 한쪽에 갇혀 있지 않은지 복제본 경로(온도 사다리 왕복)를 기록해 확인.
